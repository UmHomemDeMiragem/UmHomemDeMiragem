### 🛠️ Projetos Técnicos (Foco em NOC, SOC, Confiabilidade & Infra)

#### 🎫 **Mesa de Serviço GLPI Corporativa (Docker)**
* Implantação e administração de Service Desk corporativo em contêineres Docker.
* Configuração completa de catálogo de serviços, categorias de chamados, matriz de priorização, regras estritas de SLA por impacto/urgência, fluxo de escalonamento N1/N2/N3 e base de conhecimento integrada.
* **Tecnologias:** GLPI, Docker, Linux, Gestão de SLA / ITIL.

#### 🕵️ **Pentester Agent CLI — Automação de Reconhecimento & Varredura**
* Agente autônomo desenvolvido em Python com arquitetura em loop *(observar ➔ planejar ➔ agir ➔ reportar)* para segurança defensiva e auditoria autorizada de sistemas.
* Módulos de reconhecimento DNS (A, MX, TXT), enumeração de portas e serviços via Nmap/Sockets, fingerprinting HTTP de tecnologias e testes de vulnerabilidade em rotas de autenticação/APIs com relatórios automáticos em Markdown e JSON.
* **Tecnologias:** Python, Nmap, Socket, DNS Resolver, Pytest.

#### 🌐 **Linkou MCP Remote — Infraestrutura Supervisionada & Relay Seguro**
* Arquitetura cliente-servidor para execução remota supervisionada com **Dual-Gate Security Tier Engine** (classificação de risco de comandos antes e durante a execução).
* Gateway de borda com **Rate Limiting por Token Bucket (HTTP 429)** para prevenção de sobrecarga/ataques DoS, proxy reverso Caddy com terminação TLS em VPS Dockerizada e isolamento de processos no Agent local (`taskkill /t /f` em Windows e grupos de processos em Linux).
* **Tecnologias:** Linux, Bash, PowerShell, Docker, Caddy, WebSockets, Node.js, Segurança em Camadas.

#### 🔒 **MindSimple — SecOps, Criptografia & Conformidade LGPD**
* Sustentação e engenharia de segurança em SaaS médico com **criptografia em repouso AES-256-GCM** para dados sensíveis de saúde e prontuários (estrita conformidade com **LGPD Art. 5º e Resolução CFP nº 06/2019**).
* Implementação de trilhas de auditoria para exportação de dados e consentimentos, controle de acesso granular (RBAC) e webhooks assíncronos de faturamento com validação de assinatura e idempotência.
* **Tecnologias:** Criptografia AES-256-GCM, LGPD, NextAuth, PostgreSQL, Prisma, Stripe Webhooks.
* **Acesso:** [mindsimple.com.br](https://www.mindsimple.com.br)

#### ⚙️ **Scripts de Automação para Operações de TI & Backup**
* Conjunto de ferramentas em Python e PowerShell para verificação diária de integridade de backups, alertas de expiração de credenciais, checagem de portas e parsing automatizado de logs com envio de relatórios.
* **Tecnologias:** Python, PowerShell, Bash, Cron, Task Scheduler, Syslog.
