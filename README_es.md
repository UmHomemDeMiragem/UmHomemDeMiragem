### 🛠️ Proyectos Técnicos (Enfoque en NOC, SOC, Confiabilidad e Infra)

#### 🎫 **Mesa de Servicio GLPI Corporativa (Docker)**
* Despliegue y administración de Service Desk empresarial en contenedores Docker.
* Configuración completa de catálogo de servicios, categorías de tickets, matriz de priorización, reglas estrictas de SLA, escalado N1/N2/N3 y base de conocimiento integrada.
* **Tecnologías:** GLPI, Docker, Linux, Gestión de SLA / ITIL.

#### 🕵️ **Pentester Agent CLI — Automatización de Reconocimiento y Escaneo**
* Agente autónomo desarrollado en Python con ciclo de ejecución *(observar ➔ planificar ➔ actuar ➔ reportar)* para auditorías de seguridad autorizadas.
* Módulos de resolución DNS, escaneo de puertos Nmap, fingerprinting HTTP y evaluación de vulnerabilidades en APIs/Auth con reportes en Markdown y JSON.
* **Tecnologías:** Python, Nmap, Socket, DNS Resolver, Pytest.

#### 🌐 **Linkou MCP Remote — Infraestructura Segura y Relay Supervisado**
* Arquitectura distribuida para operaciones remotas con motor **Dual-Gate Security Tier Engine** (clasificación de riesgo de comandos antes y durante la ejecución).
* Gateway perimetral con **Rate Limiting por Token Bucket (HTTP 429)** contra ataques DoS, proxy inverso Caddy con TLS en VPS Dockerizada y aislamiento de procesos en el Agent local (`taskkill /t /f` en Windows y grupos de procesos en Linux).
* **Tecnologías:** Linux, Bash, PowerShell, Docker, Caddy, WebSockets, Node.js, Seguridad en Capas.

#### 🔒 **MindSimple — SecOps, Criptografía y Cumplimiento de Privacidad (LGPD)**
* Mantenimiento e ingeniería de seguridad en SaaS clínico con **cifrado en reposo AES-256-GCM** para expedientes médicos y datos sensibles de salud.
* Pistas de auditoría para consentimiento de usuarios, control granular RBAC y webhooks asíncronos de facturación con validación criptográfica e idempotencia.
* **Tecnologías:** Cifrado AES-256-GCM, LGPD, NextAuth, PostgreSQL, Prisma, Stripe Webhooks.
* **Acceso:** [mindsimple.com.br](https://www.mindsimple.com.br)

#### ⚙️ **Scripts de Automatización para TI y Respaldo**
* Herramientas en Python y PowerShell para verificación diaria de checksums de copias de seguridad, alertas de expiración de credenciales y análisis automatizado de logs.
* **Tecnologías:** Python, PowerShell, Bash, Cron, Task Scheduler, Syslog.
