### 🛠️ 技术项目 (聚焦 NOC, SOC, 系统可靠性与基础设施)

#### 🎫 **企业级 GLPI 智能服务台 (Docker)**
* 在 Docker 容器中完整部署并管理企业级 GLPI Service Desk 运维平台。
* 配置服务目录、工单流转矩阵、基于紧急程度与影响范围的 SLA 自动化规则、N1/N2/N3 升级流及知识库。
* **技术栈：** GLPI, Docker, Linux, SLA / ITIL 最佳实践。

#### 🕵️ **Pentester Agent CLI — 自动化靶向侦察与漏洞探测代理**
* 基于 Python 构建的自主安全 CLI 代理，采用 *(感知 ➔ 规划 ➔ 执行 ➔ 报告)* 架构，面向授权安全审计。
* 具备 DNS 记录深度解析、Nmap 端口与服务发现、HTTP 指纹嗅探、API 认证漏洞扫描功能，自动生成 Markdown 与 JSON 报告。
* **技术栈：** Python, Nmap, Socket, DNS Resolver, Pytest, Docker。

#### 🌐 **Linkou MCP Remote — 安全中继与远程受控基础设施**
* 具备 **Dual-Gate Security Tier Engine**（命令事前与运行时双重安全风险分级机制）的受控远程执行平台。
* 边缘网关集成基于 **Token Bucket 令牌桶算法的限流机制 (HTTP 429)** 防御 DoS 攻击，基于 Caddy 反向代理实现 VPS TLS 加密，保障本地守护进程生命周期安全 teardown。
* **技术栈：** Linux, Bash, PowerShell, Docker, Caddy, WebSockets, Node.js。

#### 🔒 **MindSimple — SecOps 运维、敏感数据加密与隐私合规**
* 面向医疗 SaaS 平台的安全架构实践：对病历与敏感健康数据实施 **AES-256-GCM 静态加密存储**（遵循巴西通用数据保护法 **LGPD 第5条与 CFP 第 06/2019 号决议**）。
* 构建完备的合规审计流、细粒度 RBAC 与具备防重放幂等机制的 Stripe 异步 Webhook 处理管道。
* **技术栈：** AES-256-GCM 加密, LGPD 合规, NextAuth, PostgreSQL, Prisma, Stripe Webhooks。
* **访问入口：** [mindsimple.com.br](https://www.mindsimple.com.br)
