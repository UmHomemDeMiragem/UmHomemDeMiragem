`Июнь 2025 – настоящее время` • `Бразилиа, Бразилия`
* **Техническая поддержка N1/N2/N3 и Service Desk:** Прямое консультирование и решение проблем конечных пользователей корпоративных сервисов и рабочих станций.
* **Управление инцидентами и SLA:** Прием, приоритизация и эскалация обращений с детальным протоколированием, сохраняя показатель **95% решений в рамках SLA**.
* **Превентивный мониторинг (NOC):** Непрерывный контроль состояния и доступности продуктивных серверов для **150+ пользователей**, поддерживая аптайм **99,5%**.
* **Траблшутинг и анализ журналов:** Диагностика первопричин (RCA) на серверах **Windows Server и Linux (Ubuntu/Debian)**, анализ трафика и логов.
* **Управление доступом (RBAC/IAM):** Администрирование ролевых моделей доступа и разделение полномочий между отделами продаж, операций и руководством.
* **Харденинг и стандарты:** Обслуживание баз данных PostgreSQL, создание стандартных регламентов (SOP) и пополнение базы знаний.

* **Анализ угроз и фишинга:** Выявление аномалий, проверка подозрительных писем и сбор цифровых доказательств для расследования инцидентов.
* **Автоматизация инфраструктуры:** Разработка скриптов на **Python** для автоматической проверки целостности резервных копий (**снижение ручного труда на 70%**).
* **Оценка уязвимостей и IAM:** Настройка политик IAM/RBAC, участие в сканировании инфраструктуры (Nessus/OpenVAS) и проведение инструктажей по кибергигиене.

### 🛠️ Технические проекты (NOC, SOC, Безопасность и Инфраструктура)

#### 🎫 **Корпоративный Service Desk GLPI (Docker)**
* Развертывание и управление системой Service Desk GLPI в контейнерах Docker.
* Настройка каталогов услуг, матриц приоритетов, правил SLA, регламентов эскалации N1/N2/N3 и корпоративной базы знаний.
* **Стек:** GLPI, Docker, Linux, Управление SLA / ITIL.

#### 🕵️ **Pentester Agent CLI — Автономный агент разведки и сканирования**
* Автономный CLI-инструмент на Python с циклом исполнения *(наблюдение ➔ планирование ➔ действие ➔ отчет)* для авторизованного аудита безопасности.
* Модули резолва DNS, сканирования портов Nmap, фингерпринтинга HTTP и тестирования уязвимостей API/Auth с генерацией отчетов в Markdown и JSON.
* **Стек:** Python, Nmap, Socket, DNS Resolver, Pytest.

#### 🌐 **Linkou MCP Remote — Защищенная инфраструктура и удаленный релей**
* Распределенная архитектура для безопасных удаленных операций с движком **Dual-Gate Security Tier Engine** (классификация рисков команд до и во время исполнения).
* Шлюз с **Rate Limiting по алгоритму Token Bucket (HTTP 429)** против DoS-атак, реверс-прокси Caddy с TLS на VPS в Docker и изоляция процессов в локальном агенте.
* **Стек:** Linux, Bash, PowerShell, Docker, Caddy, WebSockets, Node.js.

#### 🔒 **MindSimple — SecOps, шифрование и соответствие LGPD**
* Инженерия безопасности в медицинском SaaS с **шифрованием в покое AES-256-GCM** для персональных и медицинских данных (в соответствии с **LGPD и стандартами CFP**).
* Аудит согласий пользователей, ролевой контроль (RBAC) и идемпотентные вебхуки Stripe Billing с проверкой цифровых подписей.
* **Стек:** Шифрование AES-256-GCM, LGPD, NextAuth, PostgreSQL, Prisma, Stripe Webhooks.
* **Ссылка:** [mindsimple.com.br](https://www.mindsimple.com.br)

#### ⚙️ **Скрипты автоматизации ИТ-операций и резервного копирования**
* Пакет скриптов на Python и PowerShell для проверки контрольных сумм бэкапов, оповещения об истечении сертификатов и мониторинга логов.
* **Стек:** Python, PowerShell, Bash, Cron, Task Scheduler, Syslog.
