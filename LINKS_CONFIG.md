# 🔗 Guia de Configuração de Links do README

Este documento fornece instruções detalhadas sobre como configurar todos os links de perfil nos arquivos README.

## 📋 Lista de Links a Configurar

### 1. LinkedIn
**Onde encontrar:** Acesse seu perfil no LinkedIn e copie a URL da barra de endereços.
- **Formato:** `https://www.linkedin.com/in/seu-usuario/`
- **Exemplo:** `https://www.linkedin.com/in/johndoe/`
- **Arquivos a atualizar:**
  - `README.md` (linha ~30): `[Your LinkedIn Profile URL]`
  - `README_pt-br.md` (linha ~30): `[URL do seu Perfil do LinkedIn]`
  - `README_es.md` (linha ~30): `[URL de tu perfil de LinkedIn]`
  - `README_ru.md` (linha ~30): `[Ваш URL-адрес профиля LinkedIn]`
  - `README_zh.md` (linha ~30): `[你的领英个人资料URL]`

### 5. Discord
**Onde encontrar:** Você pode usar um link de convite do seu servidor ou criar um link personalizado.
- **Formato:** `https://discord.gg/seu-codigo-de-convite` ou `https://discord.com/users/seu-id-de-usuario`
- **Exemplo:** `https://discord.gg/AbC123` ou `https://discord.com/users/123456789012345678`
- **Como obter seu ID do Discord:**
  1. Ative o Modo Desenvolvedor: Configurações → Avançado → Modo Desenvolvedor
  2. Clique com botão direito no seu nome e selecione "Copiar ID"
- **Arquivos a atualizar:**
  - `README.md` (linha ~35 e ~188): `[Your Discord ID Link]`
  - `README_pt-br.md` (linha ~35 e ~188): `[Link do seu ID Discord]`

### 9. WakaTime (Opcional)
**Onde encontrar:** Se você usa WakaTime, crie uma conta em https://wakatime.com e obtenha seu nome de usuário.
- **Formato:** Seu nome de usuário do WakaTime (sem @)
- **Exemplo:** `johndoe`
- **Como usar:**
  1. Descomente as linhas do WakaTime nos arquivos README
  2. Substitua `SEU_WAKATIME_USERNAME` pelo seu nome de usuário
- **Arquivos a atualizar:**
  - Todas as versões do README (linha ~175): Descomente e substitua `SEU_WAKATIME_USERNAME`

## 🔄 Como Atualizar os Links

### Método 1: Edição Manual
1. Abra cada arquivo README em um editor de texto
2. Use Ctrl+F (ou Cmd+F no Mac) para procurar os textos entre colchetes `[...]`
3. Substitua o texto placeholder pela URL real
4. Salve o arquivo

### Método 2: Buscar e Substituir em Lote (Recomendado)
Use o seguinte comando para encontrar todos os placeholders:

```bash
# No Linux/Mac/Git Bash:
grep -n "\[Your\|\[URL\|\[Seu\|SEU_WAKATIME" README*.md
```

Depois substitua manualmente cada placeholder com o link correto.

## 💡 Dicas Importantes
